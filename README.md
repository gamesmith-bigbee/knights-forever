KINGDOM KNIGHT — PROTOTYPE 0.3

This build is designed around the supplied character assets.

Files:
- index.html
- assets/knight/idle-front.png
- assets/knight/attack.png
- assets/knight/back.png

Mobile:
- Portrait-first UI
- Pointer/touch events
- Hold-to-defend
- Swipe-to-attack
- No page scrolling during play
- Uses dynamic viewport height (dvh)

To test on a phone:
Upload the contents of this folder to any static HTTPS host.
Then open the resulting HTTPS URL on the phone.

GitHub Pages, Netlify, Cloudflare Pages, or similar static hosting will work.

The supplied white backgrounds were removed and the images were cropped to their visible character bounds.
